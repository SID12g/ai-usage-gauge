# Changelog

## 0.2.1

First Marketplace release.

- Shows the remaining Claude (5-hour, weekly) and ChatGPT Codex usage limits in the status bar
- Tooltip with each limit's remaining share, reset time, and plan
- Warning color at 25% or less remaining, error color at 10% or less
- Usage results shared across VS Code windows
- Settings: refresh interval, per-service visibility, codex executable path
- English and Korean UI, following VS Code's display language
